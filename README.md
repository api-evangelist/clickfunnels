ClickFunnels is a sales funnel and online business platform that lets entrepreneurs build landing pages, sales funnels, checkout flows, courses, membership sites, and email marketing campaigns without code. The ClickFunnels 2.0 REST API gives developers programmatic access to workspaces, funnels, pages, products, contacts, orders, and subscriptions, authenticated with Bearer tokens or OAuth 2.0.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/clickfunnels/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/clickfunnels/refs/heads/main/apis.yml)

## APIs

### ClickFunnels 2.0 API

REST API for managing workspaces, funnels, pages, products, contacts, orders, subscriptions, and courses in ClickFunnels 2.0. Authentication uses an API access token as a Bearer token, or OAuth 2.0 for public integrations.

- **Human URL:** [https://developers.myclickfunnels.com](https://developers.myclickfunnels.com)
- **Base URL:** `https://accounts.myclickfunnels.com/api/v2`
